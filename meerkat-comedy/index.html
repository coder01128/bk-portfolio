Case Study — Meerkat Comedy

Backstage tools for a live comedy night in Johannesburg.

Rightside Entertainment needed offline production tools for their Meerkat Comedy shows — audience meters, act controllers, and giveaway systems, all running from a single browser tab with no internet required.

Scroll

The Brief

A growing show with a manual backstage.

Meerkat Comedy is a live stand-up night in Johannesburg run by Rightside Entertainment in partnership with Ster-Kinekor Cinemas.

They needed tools that worked in a venue without Wi-Fi, ran from a single laptop, and could be operated by someone who isn't a developer. No apps to install. No accounts to create. Just open a file and run the show.

The result is three purpose-built browser tools — each a single HTML file with no dependencies, no server, and no internet needed at showtime.

The toolkit also covers the on-screen visuals — animated prize wheel spins, full-screen winner reveals, act transition graphics, and the Meerkat Meter's real-time LED applause bar with confetti on new peaks. These render in the browser with no external dependencies. Neon intro animations were pre-rendered in Python with Manim.

The Toolkit

Three tools. One production stack.

Tool Spotlight Controller

The show's nerve centre. A single HTML file opens three synchronised popup windows — Winner, Wheel, and Acts — all controlled from one master dashboard. Sound effects are Base64-embedded, so playback has no load delay. No server, no internet, no dependencies.

postMessage sync Base64 audio Multi-window Offline
Tool Meerkat Meter

A real-time applause visualiser. A vertical LED-style bar responds to venue audio input with per-act peak markers for comparing crowd responses across the night. A new record triggers confetti. Adjustable sensitivity accounts for different venue acoustics.

Web Audio API Peak tracking Confetti FX Sensitivity tuning
Tool Acts Manager

On-demand act control with clickable buttons for each performer. Syncs with the Meter for a unified backstage view. The host sees everything on one screen — who's up, who's next, and how the crowd responded.
