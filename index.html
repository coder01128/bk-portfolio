Contract Scorer

Problem

Car dealerships sign vendor contracts without knowing if pricing, terms, or cancellation clauses are fair. Manual review misses escalators, hidden fees, and unfavourable data rights.

Solution

Upload a vendor agreement (PDF). A vision model extracts structured fields and a weighted scoring engine evaluates the deal — Pricing 40%, Terms 30%, Flexibility 30%. Multi-tenant auth with dealership-level accounts and row-level security.

Outcome

Dashboard with Deal Score, subscores, market comparisons, and AI-generated negotiation talking points. Each dealership's data is fully isolated.

Bank Statement Pipeline

Problem

South African accountants manually extract transactions from password-protected bank statements. Different banks, different formats, hours of data entry — and one misread number means the books don't balance.

Solution

Batch unlock statements from any SA bank, extract transactions via vision model, reconcile every extraction against the statement's own printed totals. Self-correcting: flags mismatches and re-runs extraction instead of passing bad data downstream.

Outcome

Fully client-side — no data leaves the browser. Handles any SA bank format. Catches the non-deterministic errors that vision extraction introduces before they reach the books.

FashionKiller — three tools, one retail business

Problem

Solution

Agency Content Pipeline

Problem

Agency website projects start with a client brief and end with copy manually written and pasted into WordPress page by page. Slow, inconsistent, no review gate before content goes live.

Solution

LangGraph agent takes a brief, generates section-by-section copy via Anthropic API tool use, checks the WordPress site's existing page structure, and pushes draft pages. Human approval gate before anything publishes.

Outcome

41/41 tests passing, 15 conventional commits, live end-to-end run confirmed. Built in one day.
